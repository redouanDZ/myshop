# متجر الإلكتروني - E-commerce Store

## نظرة عامة
مشروع متجر إلكتروني احترافي مصمم لتقديم تجربة تسوق سلسة وسهلة للعملاء. المتجر يدعم اللغة العربية بالكامل مع تصميم متجاوب يعمل على جميع الأجهزة.

## الميزات
- واجهة مستخدم احترافية وسهلة الاستخدام
- نظام عربة تسوق متقدم
- عملية دفع آمنة وموثوقة
- تصفية وتنظيم المنتجات
- نظام تقييمات ومراجعات
- تصميم متجاوب يعمل على جميع الأجهزة
- دعم كامل للغة العربية (RTL)

## التقنيات المستخدمة
- HTML5 للبنية الأساسية
- CSS3 مع متغيرات CSS للتصميم
- JavaScript للتفاعلية
- Font Awesome للأيقونات
- LocalStorage لتخزين عربة التسوق محلياً

## هيكل المشروع

myshop/
├── admin/          # لوحة تحكم المسؤول (قادم قريباً)

## كيفية البدء
1. قم بتنزيل أو استنسخ **المشروع**.
2. افتح المجلد الرئيسي للمشروع.
3. افتح ملف `index.html` في متصفح الويب.

## التخصيص

### تغيير الشعار والهوية البصرية
1. ابحث عن `.logo` في ملف `css/style.css`.
2. عدّل متغيرات الألوان في قسم `:root` لتغيير الألوان الرئيسية.
3. استبدل صور الشعار في قسم الهيدر.

### إضافة المنتجات
1. أضف صور المنتجات في مجلد `images/`.
2. قم بتحديث معلومات المنتجات في ملف `js/main.js`.
3. أو يمكنك إنشاء قاعدة بيانات وربطها بالواجهة.
